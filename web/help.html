How this board works

A Card is one unit of work, and the board - its Columns and the Comments written on each Card - is all that you and an agent share.

The path a Card takes

  1. File a Card in inbox - a title and a sentence or two - and triage it there: a priority, then a move to ready, backlog or blocked. Nothing is worked while it waits in inbox.
  2. An agent takes a Card from ready into doing, where the board holds it to that agent.
  3. Comment on a Card in doing, or move it to blocked with a Comment saying why.
  4. Drag a Card to other columns and vertically to re-order.
  5. An agent moves it into done when its work is committed, naming that commit; no move of yours can put a Card there. Closing it is yours alone, and a closed Card waits in closed, which the page shows only when you ask for it.

Reading a Card's face

  • A priority is a stripe on a Card's edge, in a quiet colour. A Card you filed wears it on the left edge; a Card an agent filed wears it on the right, and a Card an agent is holding keeps it on the left inside the orange edge below.
  • A blue * before a title means an agent filed that Card and nobody has opened it since; opening it takes the asterisk off. A bubble beside a number counts the Comments a Card carries, and the same blue on it counts Comments an agent filed.
  • A thick orange edge means an agent is holding that Card, and a drag is how you let it go.
  • A Card with steps prints how far through them it is as 2/3, and a line of rungs under its meta line: one per step, filled for each one done. A Card in done still showing a step open wears the red a contradicted Card wears, its open rungs with it.

Your actions

  • Add a Card, and decide what waits in inbox.
  • File a step in a Card view by writing its name under the ladder, tick one to mark it done, untick one to open it again, or press the trash glyph beside it to erase it - its rung then says *erased* and its number stays spent, never handed to a later step. A Card an agent is holding has its steps shut - they are that agent's to work until you drag the Card out of doing.
  • Close a Card, or delete one - an agent can do neither. A done Card still showing a step open will not close: tick its steps, or drag it back off done.
  • Release a Card an agent left claimed, by dragging it out of doing.

The agent's actions

  • Take a Card from ready into doing, which claims it for that agent.
  • Move a Card between the other Columns, and Comment on it, including why it is blocked.
  • File a finished Card into done with its commit's hash, or give a Card up back to the Column it came from.

This page

Esc or a click beside this dialog closes it; a Card view closes the same two ways, and they ask first when you have typed words that are not saved - the close button never asks, because it already says it changes nothing. Type / and only Cards matching it are shown, while a Comment count - the number and its bubble - keeps each Card's total. Ctrl+S saves the Card you have open, and Ctrl+Enter files what you are typing - a new Card in the strip, a Comment in the modal; both keys write the form your caret is in, and Cmd is the same key as Ctrl here - this page answers either name without distinguishing them, so where a control's tooltip says Ctrl your keyboard's Cmd is meant. The board redraws itself every few seconds.
